# AI-resume-checker
AI Engineering project for testing LLM behavior, prompt optimization, structured JSON outputs, and building a robust Python Gemini pipeline for resume–job description matching.
# AI Engineering Challenge – LLM Audit & Gemini Pipeline

This project was developed as part of an AI Engineering internship assessment.

The project focuses on testing and improving LLM-based systems through adversarial testing, prompt engineering, structured JSON outputs, and a Python-based Gemini API pipeline.

## Key Components

- Adversarial testing of AI system behavior
- Prompt injection and edge-case testing
- Resume and job description analysis
- Gemini API integration using Python
- Structured JSON response generation
- JSON validation and sanitization
- API error and retry handling
- Resume–Job Description matching
- Documentation and failure analysis
